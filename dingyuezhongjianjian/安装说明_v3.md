# 订阅风控中间件（全功能版）安装说明

---

## 第一步：放置文件

将 `SubscribeRiskControl_v3.php` 改名后放到：
```
app/Http/Middleware/SubscribeRiskControl.php
```

修改文件顶部配置区：

```php
const RATE_LIMIT       = 5;                      // 60 秒内最多几次
const RATE_WINDOW      = 60;                     // 时间窗口（秒）
const TELEGRAM_TOKEN   = 'your_bot_token_here';  // ← 改成你的
const TELEGRAM_CHAT_ID = 'your_chat_id_here';    // ← 改成你的
const BAN_THRESHOLD    = 3;                      // 7 天内触发几次后封禁
const BAN_MIN_SCORE    = 60;                     // 触发封禁的最低单次评分
const BAN_WINDOW       = 7;                      // 累计统计窗口（天）
```

---

## 第二步：建数据库表

```sql
CREATE TABLE risk_logs (
  id           BIGINT AUTO_INCREMENT PRIMARY KEY,
  user_id      BIGINT NOT NULL,
  email        VARCHAR(255),
  ip           VARCHAR(45),
  user_agent   VARCHAR(255),
  risk_score   TINYINT DEFAULT 0,
  reason       VARCHAR(255),
  detected_at  TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  created_at   TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  INDEX idx_user  (user_id),
  INDEX idx_score (risk_score)
);
```

> 如果你已经建过旧版的表，执行这两行追加字段即可：
> ```sql
> ALTER TABLE risk_logs ADD COLUMN email VARCHAR(255) AFTER user_id;
> ALTER TABLE risk_logs ADD COLUMN user_agent VARCHAR(255) AFTER ip;
> ```

---

## 第三步：添加日志通道

打开 `config/logging.php`，在 `channels` 数组里加：

```php
'risk' => [
    'driver' => 'daily',
    'path'   => storage_path('logs/risk.log'),
    'level'  => 'debug',
    'days'   => 30,
],
```

## 第五步：注册中间件

`app/Http/Kernel.php` 的 `$routeMiddleware` 加一行：

```php
'subscribe.risk' => \App\Http\Middleware\SubscribeRiskControl::class,
```

---

## 第六步：挂载路由

```php
Route::get('/api/v1/client/subscribe', [ClientController::class, 'subscribe'])
    ->middleware('subscribe.risk');
```

---

## 触发逻辑说明

```
首次触发（评分 60+）→ 写库 + 写日志 + Telegram 告警，7天计数 +1
第 2 次触发          → 同上，计数变为 2
第 3 次触发（评分 60+）→ 同上 + 自动封禁用户，Telegram 显示"已自动封禁"
```

调整 `BAN_THRESHOLD` 和 `BAN_MIN_SCORE` 可以控制封禁的严格程度。

---

## 日常运维

**实时看日志：**
```bash
tail -f storage/logs/risk-$(date +%Y-%m-%d).log
```

**解除频率限制：**
```bash
redis-cli DEL sub_rate:{用户ID}
```

**解除封禁并清除累计计数：**
```bash
redis-cli DEL sub_risk_count:{用户ID}
# 数据库里把 banned 改回 0
UPDATE users SET banned = 0 WHERE id = {用户ID};
```

**查看近期高风险记录：**
```sql
SELECT user_id, email, ip, user_agent, risk_score, reason, detected_at
FROM risk_logs
WHERE risk_score >= 60
ORDER BY detected_at DESC
LIMIT 50;
```
