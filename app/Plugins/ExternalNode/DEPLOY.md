## 一、 适用环境与准备工作

* **适用面板**：V2Board (v1.6.x / v1.7.x)、Xboard 以及各大魔改分支；
* **PHP 版本**：PHP 7.4 / 8.0 / 8.1 / 8.2（需开启 `curl`、`json` 扩展，默认均自带）；
* **无需环境**：**无需** 安装 Node.js，**无需** 运行 npm 编译，**无需** 导入任何 SQL 数据库文件。

---

## 二、 极速安装与部署 (只需 2 步)

### 步骤 1：上传插件文件夹
将 `ExternalNode` 整个文件夹，上传或解压到你网站根目录的 `app/Plugins/` 下：
```text
/www/wwwroot/你的网站目录/app/Plugins/ExternalNode/
```
*(上传完毕后，确保 `ExternalNode` 目录与子文件拥有 `www:www` 读写权限)*

---

### 步骤 2：启用挂载 (二选一，推荐方式 A)

#### 推荐方式 A (无感服务提供者挂载，系统升级不冲突)：
打开网站目录下的 `app/Providers/AppServiceProvider.php`，找到 `register()` 方法，添加以下 3 行代码：

```php
public function register()
{
    // 🛡️ ExternalNode 商业独立插件自动挂载 (目录存在即生效，删除即自动静默卸载)
    if (class_exists(\App\Plugins\ExternalNode\ExternalNodeServiceProvider::class)) {
        $this->app->register(\App\Plugins\ExternalNode\ExternalNodeServiceProvider::class);
    }
}
```

#### 备用方式 B (路由末尾直接引入)：
打开网站目录下的 `routes/web.php`，在**最末尾**追加一行：
```php
@include_once app_path('Plugins/ExternalNode/routes.php');
```

> 恭喜！此时插件已经成功挂载并生效！

## 三、 宝塔计划任务自动调度配置

为了让系统**自动定时从全网采集节点、并发测活剔除死节点、自动清理长期离线节点**，需在宝塔添加一条常驻定时任务：

1. 打开 **宝塔面板 $\to$ 计划任务**；
2. 任务类型选择：**Shell 脚本**；
3. 任务名称填写：`ExternalNode 外部节点自动调度`；
4. 执行周期设置为：**N 分钟**（建议 `5` 或 `10` 分钟执行一次）；
5. 脚本内容填写：
   ```bash
   cd /www/wwwroot/你的网站目录 && php artisan external:cron >> /dev/null 2>&1
   ```
6. 点击 **添加任务** 并手动点击一次“执行”，确认状态正常。

## 四、 打开可视化 Web 控制台与安全解锁

插件自带极致现代化的独立自包含 Web 管理面板，**开箱即用，无需编译**！

### 1. 访问控制台
在浏览器中打开：
👉 **`https://你的域名/admin/external-nodes`**
*(亦可通过完整接口路径访问：`https://你的域名/api/v1/admin/plugin/external-node/dashboard`)*

### 2. 双重安全解锁
为了防止公网扫描器探测与恶意篡改，控制台内置了**银行级安全双重鉴权**：
* **情境 1（免密直通）**：如果你的浏览器刚刚登录过 V2Board 管理后台，系统会自动识别管理员身份，**免密直接进入**！
* **情境 2（安全锁屏）**：若在无痕模式或直接被扫描器探测，页面会自动弹出**毛玻璃安全锁**，必须输入管理通信密钥才能解锁。

#### 🔑 如何查看或修改你的安全密钥？
1. 查看服务器上的文件：
   `/www/wwwroot/你的网站目录/storage/app/external_nodes.json`
2. 找到 `settings.admin_secret_key` 字段，里面的字符串就是你的初始密码；
3. **自定义密码**：你可以直接将该字段修改为你自定义的任意强密码（如 `MyPass2026!`），保存后立即生效！

## 五、 如何将免费引流订阅对接给用户

本插件的核心杀手锏是**免费引流与付费核心专线 100% 物理隔离**，绝不弄脏自建节点。

### 1. 免费引流独立订阅地址格式
* **Clash / MOMclash 专属格式**：
  `https://你的域名/api/v1/free/subscribe?token={用户token}&flag=clash`
* **通用 Base64 格式 (小火箭 / V2rayN)**：
  `https://你的域名/api/v1/free/subscribe?token={用户token}`

### 2. 用户中心 / 主题模板如何展示？
可以在前端用户中心为免费用户或新注册用户展示一个单独的卡片：
> **「免费体验线路」** $\to$ 点击复制对应的免费订阅链接。
> 用户每次在客户端更新订阅，系统在后台**自动扣除设定的流量（如 1GB）**，额度用尽即停止下发，防白嫖怪滥用。

## 六、 进阶防封指南：配置独立引流域名

免费节点容易引来爬虫或被墙，**强烈建议为免费订阅通道配置一个独立的免备案/便宜二级域名**（如 `free-sub.yourdomain.com`）：

1. 在宝塔或 Cloudflare 添加该二级域名；
2. 反代或直接绑定到该网站，并在 Nginx 中将请求指向 `/api/v1/free/subscribe`；
3. **巨大优势**：哪怕这个引流域名被 GFW 拦截或被封，**你的付费老用户正规专线订阅（`/api/v1/client/subscribe`）与主站核心域名毫发无损！**

## 七、 彻底卸载与应急恢复 (零残留)

如果你哪天不想使用本插件，或者需要迁移/升级系统：

1. 删除 `app/Providers/AppServiceProvider.php` 中添加的 3 行代码（或删除 `routes/web.php` 末尾追加的一行）；
2. 删除插件目录：`app/Plugins/ExternalNode/`；
3. （可选）删除持久化缓存文件：`storage/app/external_nodes.json`。

> **卸载结果**：由于插件**零数据库改动**，删除后原生系统立即 100% 恢复初始状态，数据库中**绝对没有留下任何一张孤儿表或废弃垃圾字段**。
